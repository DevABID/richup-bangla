Custom game sounds
==================

Put an audio file here to replace one of the game's built-in sounds:

  build.mp3  - plays when a player builds a house or hotel
               (played for at most 5 seconds, with a short fade-out)

If the file isn't here, the game uses its own original sound instead.

Only add audio you have the right to use. This folder is published with the
game, so anything in it is publicly downloadable and part of your public
GitHub repository.
